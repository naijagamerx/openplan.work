1. Getting Started

First-Time Setup

  1. 1Open your browser and navigate to your OpenPlan Work URL
  2. 2Click "Get Started" on the welcome page
  3. 3Create your admin account:
    • Enter your email address
    • Create a password (minimum 8 characters)
    • IMPORTANT: Create a master password - this encrypts all your data and cannot be recovered if lost!
  4. 4Configure your business:
    • Business name
    • Currency preference (USD, EUR, GBP, ZAR)
    • Tax rate
  5. 5Setup AI features (optional):
    • Add Groq API key for free AI
    • Add OpenRouter API key for premium AI models
  6. 6Click "Complete Setup" - you'll be redirected to your dashboard!
Important: Your master password is the key to all your data. Write it down and store it securely. Without it, your data cannot be recovered!

Daily Login

  1. 1Enter your email and password
  2. 2Enter your master password to decrypt your data
  3. 3Click "Login"
Tip: Check "Remember me" to stay logged in longer. You can adjust session timeout in Settings.

3. Dashboard

The Dashboard is your home base - it shows an overview of everything happening in your workspace.

Dashboard Features

📊 Statistics Cards

At the top of the dashboard, you'll see key metrics:

  • Total Tasks: Number of active tasks
  • Tasks Due Today: Urgent tasks needing attention

🎯 Habit Streaks

Quick log your water intake. Shows today's progress toward your daily goal.

📅 Upcoming

4. Tasks & Projects

Figure 2: Tasks Management Page

Creating a Task

Method 1: Quick Add Button

  1. Click the + button in the header
  2. Select "Task" from the menu
  3. Enter task title and details
  4. Click Create

Method 2: From Tasks Page

  1. Go to Tasks in the sidebar
  2. Click + New Task button
  3. Fill in the task form:
    • Title: What needs to be done
    • Description: Additional details (optional)
    • Project: Link to a project (optional)
    • Status: Backlog, Todo, In Progress, Review, Done
    • Priority: Low, Medium, High, Urgent
    • Due Date: When is it due?
    • Estimated Time: How long will it take? (minutes)
  4. Click Create Task

Managing Tasks

Task Status Workflow

Tasks move through these stages:

Status Description
BacklogIdea or future task - not actively working on
TodoReady to start - added to your todo list
In ProgressCurrently working on this task
ReviewCompleted, needs review or approval
DoneFinished and approved

Task Actions

On any task, you can:

  • View: Click the task to see full details
  • Edit: Click the edit icon to modify
  • Complete: Click the checkmark to mark done
  • Delete: Click the trash icon to remove
  • Add Subtask: Break down into smaller steps
  • Track Time: Log time spent on task

Working with Subtasks

  1. Open a task
  2. Scroll to Subtasks section
  3. Click + Add Subtask
  4. Enter subtask title
  5. Optionally add estimated time
  6. Click Add
Tip: Use subtasks to break down complex tasks. Check them off as you complete each piece!

Figure 11: Inventory Management Page

Time Tracking

  1. Open a task
  2. Scroll to Time Entries section
  3. Click + Add Time Entry
  4. Enter:
    • Date: When did you work?
    • Minutes: How long did you work?
    • Description: What did you accomplish?
  5. Click Add Entry

Creating Projects

  1. Go to Projects in the sidebar
  2. Click + New Project
  3. Fill in project details:
    • Name: Project name
    • Description: What is this project about?
    • Client: Link to a client (optional)
    • Status: Active, Completed, On Hold, Cancelled
    • Color: Pick a color for visual organization
  4. Click Create Project

Project View

When you open a project, you'll see:

Figure 3: Projects Management Page

  • Project Details: Name, description, client link
  • Project Tasks: All tasks in this project
  • Project Stats: Total tasks, completed, pending
  • Add Task: Quickly add tasks to this project

Kanban Board

View your tasks as a Kanban board:

  1. Go to Tasks
  2. Click the Board View icon (grid icon)
  3. Drag tasks between columns to change status
  4. Click Save to apply changes

Task Templates

Save time by creating reusable task templates:

  1. Create a task with all the details you want to reuse
  2. Click Save as Template
  3. Give your template a name
  4. Next time, click From Template when creating a task

6. Invoices

Creating a Standard Invoice

Figure 13: Invoices Page

  1. Go to Invoices in the sidebar
  2. Click + New Invoice
  3. Select or create a Client
  4. Optionally select a Project
  5. Add line items:
    • Description: What are you billing for?
    • Quantity: How many?
    • Unit Price: Price per unit
    • Click + Add Item for more lines
  6. Set invoice details:
    • Currency: USD, EUR, GBP, or ZAR
    • Due Date: When is payment due?
    • Notes: Additional notes (optional)
  7. Click Create Invoice

Invoice Status

Status Description
DraftNot yet sent to client
SentInvoice has been sent
PaidPayment received
OverduePast due date, not paid
CancelledInvoice cancelled

Invoice Actions

  • View: See full invoice details
  • Print: Generate PDF for printing/emailing
  • Mark as Sent: Change status to "Sent"
  • Mark as Paid: Record payment
  • Edit: Modify invoice (draft only)
  • Delete: Remove invoice

Advanced Invoice Generator

For more complex invoices, use the Advanced Invoice Generator:

  1. Go to Invoices
  2. Click Advanced Invoices
  3. Click + Create Advanced Invoice
  4. Customize your invoice:
    • Company Header: Add logo, company details
    • Customer Details: Full customer information
    • Line Items: Date, reference, description, amount
    • Payment Details: Bank info, due date, reference
    • Custom Fields: Add any extra fields you need
    • Footer Text: Terms, thank you message
  5. Click Create Invoice
Tip: Use Advanced Invoices for professional billing with custom branding, payment details, and terms.

Habit Tracker

Creating a Habit

  2. Click + New Habit
  3. Fill in habit details:
    • Name: What habit do you want to track?
    • Category: Health, work, personal, etc.

Tracking Habits

  • Each habit shows a checkbox for today

Habit Timer

Some habits have a target duration. You can time yourself:

  1. Open a habit
  2. Click Start Timer
  3. Work on your habit
  4. Click Stop Timer when done
  5. The time is automatically logged

Pomodoro Timer

The Pomodoro Technique helps you focus with timed work sessions:

Figure 8: Pomodoro Focus Timer

  1. Go to Pomodoro in the sidebar
  2. Optionally select a task to work on
  3. Click Start Focus Session (25 minutes)
  4. Work until the timer ends
  5. Take a Short Break (5 minutes)
  6. After 4 sessions, take a Long Break (15 minutes)

9. AI Assistant

What is the AI Assistant?

The AI Assistant is like having a virtual assistant that can help you manage your tasks, projects, and more using natural language. It can understand what you want and take action for you!

Setting Up AI

  1. Go to Settings → AI API Keys
  2. Add an API key:
    • Groq: Free, fast AI (recommended for starters)
    • OpenRouter: Access to premium models (Claude, GPT-4, etc.)
  3. Save your API key
Note: You need an API key to use AI features. Groq offers a free tier with generous limits.

Using the AI Assistant

  1. Go to AI Assistant in the sidebar
  2. Type your request in natural language, such as:
    • "Create a task to call John tomorrow at 2pm"
    • "Add a new project for website redesign"
    • "Show me all my high priority tasks"
    • "Create an invoice for client ABC for $500"
    • "I need to track my daily meditation habit"
  3. Click Send or press Enter
  4. The AI will understand your request and take action
  5. Review what the AI did and confirm or adjust as needed

Example Conversations

Create a Client and Project

You: "Add a client called Acme Corp with email contact@acme.com, then create a website redesign project for them"

AI: Creates the client, creates the project linked to that client

Generate Multiple Tasks

You: "Create 5 tasks for the website project: design mockups, develop homepage, develop about page, testing, and deployment"

AI: Creates all 5 tasks in the project

Create an Invoice

You: "Send an invoice to Acme Corp for 10 hours of web development at $50 per hour"

AI: Creates an invoice with line item: 10 hours × $50 = $500

AI Memory

The AI Assistant remembers your conversation within the session. You can reference things you mentioned earlier:

  • "What was that client's name again?"
  • "Add another task to the project I just created"
  • "Show me the tasks for this week"
Tip: Be specific in your requests. The more details you provide, the better the AI can help!

10. Settings

Business Settings

Configure your business information:

  • Business Name
  • Email - Displayed on invoices
  • Phone
  • Address
  • Default Currency - USD, EUR, GBP, ZAR
  • Tax Rate - Applied to invoices

AI Configuration

AI API Keys

Add your AI provider API keys:

  • Groq API Key: Get free at groq.com
  • OpenRouter API Key: Get at openrouter.ai

Model Settings

Choose which AI models to use:

  • Chat Model: For AI Assistant conversations
  • Tasks Model: For generating tasks from descriptions
  • Notes Model: For AI note editing
Note: Groq models are free and fast. OpenRouter gives you access to premium models like Claude and GPT-4.

Session Settings

Choose how long you stay logged in:

  • 20 minutes - High security (auto-logout after 20min of inactivity)
  • 1 hour - Default (recommended)
  • Indefinite - Stay logged in until you logout

Backup Settings

Configure automatic backups:

  • Enable Auto-Backup: Turn on automatic backups
  • Backup Frequency: Daily, weekly, monthly
  • Retention: How many backups to keep

Data Management

Export Data

  1. Go to Settings → Data Management
  2. Choose export format:
    • JSON: Machine-readable format
    • ZIP: Complete backup with all files
  3. Click Export
  4. Save the file to your computer

Import Data

  1. Go to Settings → Import Data
  2. Choose a file (JSON or ZIP from export)
  3. Click Import
  4. Warning: This will merge with existing data
Important: Always export a backup before importing data. Imports cannot be undone!

MCP Configuration

For developers using Claude Code or other AI coding agents:

  1. Go to Settings → Developer Tools
  2. Click Generate Token (or copy existing)
  3. Copy the configuration JSON
  4. Paste into your Claude Code settings file

Custom Instructions

Tell the AI Assistant how to help you:

  1. Go to Settings → Custom Instructions
  2. Write instructions like:
    • "Always ask me before creating invoices"
    • "Set task priority to high by default"
    • "Remind me about deadlines 2 days before"
  3. Click Save

Account Settings

  • Change Password - Update your login password
  • Update Profile - Change your name or email
